---
title: テスト
---

スクリプトを直したときに、前と同じ結果になるかを自動で確かめる仕組みです。一度「この結果で正しい」と認めた実行を保存しておき、
あとから同じ入力でもう一度動かして、画面に出たものと書き出したファイルを比べます。

テストの実行では画面は一切出ません。フォーム・確認・ファイルの選択には、あらかじめ書いておいた応答が使われます。
スクリプトは写しのフォルダで動くので、本物のファイルは書き換わりません。

> いまはコマンド（`xljs test`）だけです。開発モードから記録・実行する機能は準備中です。

## ケースを作る

```
xljs test --new 月次集計 集計.js
```

スクリプトのフォルダに `.xljs/tests/月次集計/` ができます。

```
.xljs/tests/月次集計/
  case.json     応答（ここを書く）
  input/        入力ファイル（ここに置く）
  expected/     認めた結果（xljs が書く。手では書かない）
```

`input/` にテスト用の入力ファイル（個人情報を消した小さいもの）を置き、`case.json` に応答を書きます。

```json
{
  "script": "集計.js",
  "now": "2026-04-10T09:00:00",
  "answers": {
    "form": [{ "入力フォルダ": "input", "対象月": "2026-04" }],
    "confirm": [true]
  },
  "variants": {
    "月が範囲外": { "form": [{ "対象月": "2026-13" }] },
    "保存しない": { "confirm": [false] }
  }
}
```

| キー | 内容 |
|---|---|
| `script` | テストするスクリプト（スクリプトのフォルダからのパス） |
| `now` | スクリプトから見た現在の日時。今日の日付を使うスクリプトでも毎回同じ結果になる |
| `user` | `{ "userName": "...", "computerName": "..." }`。省くと `test` と `TEST-PC` |
| `args` | `xljs.args` |
| `answers` | 応答。種類ごとに、出る順に並べる |
| `variants` | パターン。名前と、`answers` から変えるところだけを書く |

### 応答

| 種類 | 書き方 |
|---|---|
| `form` | 変える値だけを書く（`{}` は既定値のまま実行）。ボタンは `"$button": "ラベル"`。ファイル・フォルダの項目は `input/売上.xlsx` のように書く |
| `confirm` | `true` / `false` |
| `prompt` | 入力する文字。`null` はキャンセル |
| `showOpenFilePicker` | パスの配列。`null` はキャンセル |
| `showSaveFilePicker` `showDirectoryPicker` | パス。`null` はキャンセル |
| `table` | 選ぶ行の番号の配列 |

- 応答のない `confirm`・`prompt`・ファイルの選択が出ると、スクリプトはそこで止まり「問題」になります（応答を足してください）。
- フォームは応答がなくなると閉じます。
- パターンは、種類ごとに 1 番目の応答を 1 番目に、2 番目を 2 番目に重ねます。変えない位置は `{}` と書きます。
- 書き間違い（知らないキー、フォームにない項目名）は、近い名前と一緒にエラーになります。

## 実行して、結果を認める

```
xljs test 集計.js
```

はじめは「未承認」と、実行の内容（出たフォーム、ログ、書き出したファイルのセル）が表示されます。内容が正しければ、認めて保存します。

```
xljs test --approve 集計.js
```

次からは、認めた結果と同じなら「OK」、違えば「失敗」と違うところが表示されます。

```
失敗    月次集計
  （- 承認済み、+ 今回）
      集計結果.xlsx 集計!B2 = "2"
  -   集計結果.xlsx 集計!C2 = "2000"
  +   集計結果.xlsx 集計!C2 = "2100"
```

- 直したせいで壊れたのなら、スクリプトを直します（AI チャットには、この違いを貼って「意図していない変更です」と伝えます）。
- 仕様を変えた結果なら、`--approve` で認め直します。

| オプション | 内容 |
|---|---|
| `--approve` | 未承認と失敗の結果を、正しいものとして保存する |
| `--only <ケース>[/<パターン>]` | そのケース（パターン）だけ実行する |
| `--timeout <秒>` | 応答なしで動き続けたときに止めるまでの時間（既定 30 秒） |
| `--json` | 結果を JSON で出力する |

終了コードは、失敗か問題があれば 1、なければ 0 です。

## 比べるもの

- 画面: フォームの項目（ラベル・種類・既定値・選択肢）、入力チェックのエラー、`alert`・`confirm` の文面、`ctx.log`・`console.log`、`ui.table`・`ctx.table` の行。
- ファイル: 増えた・変わったファイル。Excel はセルに表示される文字と数式（書式は比べません）、CSV・テキスト・JSON は行ごと。

## 注意

- `ad.me()`、`fetch`、`shell.run` を使うスクリプトは、実行する人や相手によって結果が変わることがあります。
- PDF 出力（`book.toPdf` など）は、テストでは PDF を作りません（出力しようとしたことだけを比べます）。
- アプリモード（`@mode app`）の画面の中身は比べません。
