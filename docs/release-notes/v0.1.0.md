xljs の最初のリリースです。JavaScript / TypeScript で書いたスクリプトで Excel・CSV の集計やデータ変換を行う、Windows 用のシングルバイナリです。入力して実行するツールから、一覧・検索・登録の画面を持つ業務アプリまで、HTML を書かずに作れます。Excel のインストールは不要です。

## ダウンロード

- `xljs-windows-x64.zip`: 通常の Windows（Intel / AMD）
- `xljs-windows-arm64.zip`: ARM の Windows

zip を展開し、`xljs.exe` をダブルクリックすると開始画面が開きます。使い方は [ファーストステップ](https://cool0707.github.io/xljs/guide/first-steps.html) を参照してください。

- `xljs.exe`: ふだん使う実行ファイル（ダブルクリック・ドロップで使う）
- `xljsc.exe`: コマンドプロンプト・バッチファイル・タスクスケジューラ用
- `examples\`: サンプルのスクリプトと、試すためのデータ
- `prompt\`: AI チャットに渡す資料

動作環境: Windows 10 / 11。フォーム・表・グラフ・PDF 出力の画面には WebView2 ランタイム（Windows 10 / 11 には通常入っています）を使います。

> 実行ファイルには署名がないため、初めて起動したときに「Windows によって PC が保護されました」と表示されることがあります。「詳細情報」を押してから「実行」を押してください。

## できること

- **スクリプト**: ES2023 相当の JavaScript と TypeScript。`import` でファイルを分けられます
- **Excel**: xlsx の読み書き、数式の計算、行・列の挿入・削除、シートのコピー、Excel で印刷したときと同じページの PDF 出力・印刷プレビュー
- **CSV / JSON**: Shift_JIS（CP932）/ UTF-8 の自動判定、BOM 付き UTF-8 での書き出し、JSON Lines
- **画面**: Windows のダイアログ、フォーム（入力欄・表・グラフ・タブ・ボタンを置ける画面。処理のあとも開いたまま使えます）、表、グラフ・ガントチャート、HTML の画面
- **PDF**: 結合・ページの削除・挿入・回転・文字の追加（Acrobat 不要）
- **その他**: SQLite（ファイルサーバーでの共有も）、Web API（`fetch`）、Active Directory、プログラムの実行、エクスプローラーのショートカット、VBA マクロ・数式の取り出し
- **配布**: スクリプトを exe にまとめる（`xljs pack`）、拡張子 `.xljs` の関連付け（ダブルクリックで実行）

## 作るための機能

- **開発モード**: 普段使っている AI チャット（Copilot・Gemini・ChatGPT・Claude など）とスクリプトを並べた画面。回答の差分を確かめて置き換え、その場で実行できます。エラーの場所と AI への依頼文、フォームのプレビュー、置き換えの履歴も同じ画面にあります
- **テスト**: 一度操作した内容を記録し、スクリプトを直したあとに同じ操作で再生して、出力が変わっていないかを確かめます
- **手順書**: 記録した操作から、画面の画像付きの手順書を作ります
- **デバッグ**: `--debug` でブレークポイント・ステップ実行のできるデバッグウィンドウを開きます
